Do not substitute web search result counts for Pinterest search demand or invent current Pinterest volume. Research each remaining phrase before drafting it.

Those figures compare normalized global English searches in September 2024–August 2025 with the preceding 12 months. They are **not** current October 2026 search volumes, and longer proposed titles still need query validation. ## Production requirements for every approved article

1. Check the exact primary keyword using a published Pinterest report and/or other current search evidence, as the user approved on 2026-10-10. Record the source and its limitations. Do not imply Pinterest search volume from web indexing.
2. Write original, researched copy with a distinct reason for every numbered idea, usable dimensions or constraints where relevant, and contextual links to related existing articles. Do not claim first-hand tests, project costs, or product performance without evidence.
3. Source one accurately matched, licensed image **for each idea** plus a hero. Use the source's direct image URL in the article, as requested by the user on 2026-10-10; do not generate local image files. Record the source page, photographer, license, alt text, and the idea it illustrates. Search result images and other publishers' Pinterest pins are not licensed stock.
4. The user handles Pinterest posting and pin designs. The assistant's scope is the website articles; the required `pinImage` field may use a direct licensed photo URL for the site's social preview.
5. Add `onthecorner` to frontmatter tags, choose a publish date, and update `updatedDate` only for substantive changes. Build and run `node scripts/audit_site.mjs` before deployment.
6. For static scheduled content, a deploy/rebuild is required on the intended live date; a future `publishDate` alone cannot update an already-built homepage.
